# Nonogram fixtures

The Nonogram pictures are generated by Axl, not taken from another source, so no third-party data is involved.

`scripts/generate-nonogram-fixtures.ts` builds each picture from random noise with a fixed seed per size, smooths larger sizes into blobs, sometimes mirrors them, and keeps a picture only if it passes these checks:

- between 40% and 68% of the cells are filled,
- no row or column is empty,
- it is not a duplicate, and
- the line solver in `src/nonogram-solver.ts` solves it from the clues alone.

The last check means every kept picture has exactly one solution and can be solved without guessing. The generator writes 24 pictures at 5×5, 32 at 10×10, and 24 at 15×15 to `src/nonogram-fixtures.generated.ts`. Its output never changes for the same script, and `pnpm check:generated` reruns it.

```bash
node packages/extensions/lounge/scripts/generate-nonogram-fixtures.ts
```
