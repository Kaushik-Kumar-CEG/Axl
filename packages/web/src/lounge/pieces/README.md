# Chess piece artwork

The twelve SVG files in this directory are the "Cburnett" chess pieces by Colin M. L. Burnett
(Wikimedia Commons user [Cburnett](https://commons.wikimedia.org/wiki/User:Cburnett)). They are
the same artwork Lichess calls "cburnett".

The author publishes each file under several licenses and lets the user pick one (see the
"Licensing" section of, for example,
[File:Chess klt45.svg](https://commons.wikimedia.org/wiki/File:Chess_klt45.svg)). Axl uses them
under the **3-clause BSD license**, which is compatible with Axl's Apache-2.0 license. The files
come from Wikimedia Commons, not from the Lichess repository, where the same artwork is listed
under GPL-2.0-or-later.

The only changes are removal of the XML prolog and DOCTYPE and the SPDX notices at the top of each
file. The full license text is in `LICENSES/BSD-3-Clause.txt` at the repository root.

File names: `w` or `b` for the piece color, then `K` king, `Q` queen, `R` rook, `B` bishop,
`N` knight, `P` pawn.
